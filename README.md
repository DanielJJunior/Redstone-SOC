# ⛏️ Redstone SOC

A lightweight, Minecraft-inspired Security Operations Center (SOC) built with Python to demonstrate detection engineering, file monitoring, and security automation concepts.

## Goal
Learn detection engineering, incident response, and security automation by building a simple SOC from scratch.
